# Documentation index (dev.qsp.org)

This file maps the official QSP documentation as it existed at docs commit `8dc098f` (2026-05-13). Every page listed was read in full. See [source-index.md](../source-index.md) for links.

## How the site is built

- The site is Docusaurus 3.4.0 (`<meta name="generator">` on the live intro page). The source repository is `QSPFoundation/qspfoundation.github.io`.
- `docusaurus.config.ts` sets `defaultLocale: 'en'` and `locales: ['ru', 'en']`. The files under `docs/` are the Russian originals. The English text served at `https://dev.qsp.org/docs/...` comes from `i18n/en/docusaurus-plugin-content-docs/current/`. The live intro page was fetched on 2026-10-14 and its text matched the English file.
- The sidebar is generated from the folder structure (`sidebars.ts`, `type: 'autogenerated'`).
- Code samples use the language tag `qsp`, highlighted by a custom Prism grammar (blog post 2024-08-06). This reference uses the same `qsp` tag.

## Version coverage of the docs

- The keyword index marks additions as 5.8.0 (`@`, `ARRITEM`, `FREELIB`, `INCLIB`, `LOCAL`, `LOOP`), 5.9.0 (`%`, `$CUROBJS`, `SCANSTR`, `SORTARR`), 5.9.1 (`ARRPACK`, `ARRTYPE`, `SETVAR`, `UNPACKARR`) and 5.9.4 (`MODOBJ`, `RESETOBJ`).
- The MODOBJ and RESETOBJ chapters carry the note "This chapter is translated by AI".
- Several chapters still describe 5.7.0 or 5.8.0 behavior in passing. Examples: error numbers 101 and 120 come from the 5.7.0 numbering, and the `GOSUB`/`GT` syntax lines say `[argument 8]` (the 5.7.0 limit) while other lines say `[argument 18]`.
- The docs do not mention the `EXEC` statement, the second and third `MENU` arguments, the `DELOBJ` count argument, the undefined value `?`, the `#` type prefix, or that IF branches are local scopes. All of these exist in the engine. Details are in [documentation-cross-reference.md](../engine-source-analysis/documentation-cross-reference.md).

## Differences between the Russian and English pages

The two locales have the same headings in every keyword file. Code block counts differ in three places:

| File | Russian | English | Difference |
|---|---|---|---|
| Syntaxemes | 92 fences | 88 fences | The Russian END section has two extra examples |
| Statements, `SHOWINPUT` | 6 | 4 | The Russian page has an extra `on`/`off` example |
| Functions, `$MIN` | 12 | 10 | The Russian page has an extra example |

One statement differs in meaning. In the `%` section of the syntaxemes page, the Russian text says that reading a tuple from a variable that holds another type returns an empty tuple (`[]`). The English text says it returns empty strings or zeros. Both describe the same example, whose output `[,]` comes from unpacking an empty tuple into two string variables.
