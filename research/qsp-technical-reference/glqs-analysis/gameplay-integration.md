# GLQS depends on pinned Girl Life contracts

Source comparison against Girl Life commit `83b164f64224f1ba88fd409469c1a9379ad34f86` supports the hook, menu and API contracts described here. Some actions call game procedures; others write game state directly. This comparison establishes source correspondence at that pin, with no runtime or installed-game compatibility claim. ([Pinned source](https://gitlab.com/kevinsmartstfg/girl-life/-/tree/83b164f64224f1ba88fd409469c1a9379ad34f86))

## Three entry paths share return handling

Startup sets `$onnewloc = 'LOCA'`; `LOCA` forwards transition arguments through `mod_system` to each installed mod's hook. GLQS prints its room link only outside character creation and scripted events, with its flag enabled, in the current home bedroom or the exact dorm/hotel room routes. A separate hook branch adds an entry under the base cheat menu. Settings uses `$mod_info[4]` and `mod_GLQS_options`. ([start.qsrc:23](../../../reference/nightly/locations/start.qsrc#L23), [LOCA.qsrc:27](../../../reference/nightly/locations/LOCA.qsrc#L27), [mod_system.qsrc:81](../../../reference/nightly/locations/mod_system.qsrc#L81), [03_hook.qsps:42](../../../src/03_hook.qsps#L42), [_menu_settings.qsrc:1485](../../../reference/nightly/locations/_menu_settings.qsrc#L1485))

Every entry calls `enter` before opening `start`. GLQS saves `$loc`, `$loc_arg`, `$menu_loc` and `$menu_arg`, then restores them on `leave`. This addresses the return chain through Settings and the cheat menu. It is only a partial context snapshot: upstream `setloc` also changes other variables, so the destination must rebuild its own context. The room checks match upstream current-home lookup and dorm/hotel `setloc` arguments. ([04_main_menu.qsps:78](../../../src/04_main_menu.qsps#L78), [core_library.qsrc:10](../../../reference/nightly/locations/core_library.qsrc#L10), [homes_properties.qsrc:301](../../../reference/nightly/locations/homes_properties.qsrc#L301), [uni_dorm.qsrc:1254](../../../reference/nightly/locations/uni_dorm.qsrc#L1254), [HotelRoom.qsrc:172](../../../reference/nightly/locations/HotelRoom.qsrc#L172))

## Source correspondence leaves gameplay questions open

Body-mod and fame/reputation internals were not audited against upstream in this pass. Individual clothing attributes, every NPC identity, inventory classification, court-cycle behavior, disease state and spell consequences were not traced exhaustively. Matching a route or variable does not establish all quest prerequisites or subsequent daily effects. See [implementation observations](implementation-observations.md) for specific mismatches and runtime checks, and [build and validation](build-and-validation.md) for executed checks.
